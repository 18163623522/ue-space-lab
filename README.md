# UE 空间变换 · 实验室

Unreal Engine 空间变换交互实验台（单文件 HTML，零依赖）。与课程页《UE 空间变换 · 位置与向量》配套。

## 玩法

- **三种模式大开关**：位置 P（w=1）/ 向量 v（w=0）/ 法线 n（(M⁻¹)ᵀ 对照）——同一条管线，两种乘客的命运差异一目了然
- **六站管线**：本地 → 父 → 世界 → 视图 → 裁剪 → NDC·像素，每站实时读数 + 可展开 4×4 换乘矩阵（p·w 行按模式点亮/熄灭）
- **场景全参数**：父/子帧 T·R·S（含非均匀缩放）、游戏相机（yaw/pitch/距离/水平FOV/Near/Far）、四种视口分辨率
- **P 可拖**：水平面拖动红点，全部读数联动
- **屏幕落点预览**：NDC 网格 + 像素坐标 + 屏外/背后剔除状态
- **API 对照条**：当前状态的等价蓝图调用实时生成
- 快捷键：1/2/3 切模式 · ←→ 步进 · R 复位

## 数值保证

所有读数由 UE 约定管线现场计算：行向量 p·M｜FTransform 作用序 S→R→T｜View = T(−eye)·R⁻¹·Swap｜经典透视（w′=z_view，z∈[0,1]）｜像素 = (x/2+0.5, 1−y/2−0.5)×分辨率。页面本身的 3D 画面也由同一管线渲染。
